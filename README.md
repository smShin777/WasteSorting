## 1. Business purpose
- **Project background**: 최근 코로나19 팬데믹 이후 배달 음식 및 택배 이용이 일상화되면서 국내 플라스틱 포장재 폐기물 발생량이 이전에 비해 80%나 급증했습니다. 특히 한국인의 1인당 연간 일회용 플라스틱 소비량은 배달용기 568개, 비닐봉투 533개 등의 매우 높은 수준이며, 이러한 추세가 지속될 경우 플라스틱 폐기물 발생량은 2010년 대비 약 3.6배까지 늘어날 것으로 전망됩니다.

  문제점 1: 그동안 한국의 분리배출 노력에도 불구하고 실제 '물질 재활용'이 되는 비율은 매우 낮습니다. 2021년 기준 생활계 폐기물의 물질 재활용율은 16.4%에 불과하며, 나머지 70%이상은 단순히 태워서 에너지를 얻는 방식으로 처리되고 있습니다. 특히 2025년 10월 뉴스에 따르면, 정부는 그동안 재활용률에 포함되어 있던 '열적 재활용'을 통계에서 제외하고 난 후 국내 플라스틱 재활용률은 기존 47.3%에서 36.8%로 10%포인트 이상 대폭 하락하게 되었습니다.

  문제점 2: 많은 사람들이 우유팩과 일반 종이의 구분, 내열 유리의 배출 방법등 구체적인 요령을 몰라 제대로된 분리수거를 하지 못하고 잘못된 배출로 이어져 재활용 가능 자원이 쓰레기로 버려지게 됩니다.

- **Goal**: 특정 쓰레기를 어떻게 처리해야 하는지를 단계별로 안내하여 올바른 분리배출을 할 수 있도록 하며 과태료를 부과받지 않기 위한 시스템을 구축

- **Target market**: 환경 보호에 관심이 있거나 분리수거 규칙을 헷갈리는 모든 가구

## 4. Concept of operation
 
1) 배출 품목 검색

| Purpose | 텍스트 입력만으로 원하는 품목의 배출 정보를 신속하게 얻는다 |
| :--- | :--- |
| Approach | 웹 상단의 검색창에 키워드를 입력하면, 시스템은 DB의 품목 테이블에서 매칭되는 데이터를 추출하여 결과 리스트를 보여준다 |
| Dynamics | 사용자가 버리려는 쓰레기의 명칭을 정확히 알고 있어 텍스트 검색을 수행하는 경 |
| Goals | 사용자가 복잡한 지침을 실수 없이 사용할 수 있게하여 물질 재활용률을 높이는 데 기여한다 |

2) 단계별 배출 가이드

| Purpose | 특정 품목에 대해 헷갈리기 쉬운 분리배출 기술을 정확하게 안내한다 |
| :--- | :--- |
| Approach | 레시피 형식의 인터페이스를 적용하여 4대 원칙에 따른 절차를 웹 페이지상에서 한 단계씩 제공한다 |
| Dynamics | 사용자가 식별된 품목의 상세한 분리배출 요령을 단계별로 확인하고자 하는 경우 |
| Goals | 사용자가 복잡한 지침을 실수없이 이행하여 실질적인 물질 재활용률을 높인다 |

3) FAQ

| Purpose | 영수증이나 내열유리처럼 재활용 가능 여부가 모호한 품목에 대한 해답을 제공한다 |
| :--- | :--- |
| Approach | 사용자들이 자주 묻는 품목의 처리법을 정리하여 제시함 |
| Dynamics | 검색 결과가 명확하지 않거나 특수 품목의 배출법에 의문이 생기는 경우 |
| Goals | 일상적인 혼란을 줄여 분리배출의 품질을 실질적으로 향상함 |

4) 체크리스트

| Purpose | 2024년 7월 부터 엄격해진 규정을 준수했는지 최종 확인하여 최대 30만원의 과태료 부과를 방지한다 |
| :--- | :--- |
| Approach | 배출 직전 사용자가 4가지 핵심 원칙을 체크박스 형태로 직접확인하게 한다 |
| Dynamics | 사용자가 가이드 조회를 마치고 실제 쓰레기를 배출하기 전 최종 점검을 수행하는 경우 |
| Goals | 올바른 분리배출 습관을 유도하고 사용자의 법적/경제적 불이익을 방지한다 |

5) 과태료 및 법규 정보 조회

| Purpose | 환경부의 최신 분리배출 규정 및 위반 시 불이익에 대한 정보를 제공한다 |
| :--- | :--- |
| Approach | 강화된 법규 데이터를 바탕으로 품목별 오배출 시 발생하는 과태료 금액과 기준을 도표 형식으로 제공한다 |
| Dynamics | 사용자가 강화된 분리배출 규정 및 오배출 시 발생하는 법적 불이익을 알고 싶은 경우 |
| Goals | 강화된 분리배출 정책에 대한 경각심을 높고 정확한 정보를 전달한다 |

6) 데이터 업데이트

| Purpose | 법규 변경이나 새로운 재질의 품목 등장 시 시스템 정보를 항상 최신 상태로 유지한다 |
| :--- | :--- |
| Approach | 관리자가 관리자 페이지에 접속하여 DB 서버에 저장된 품목별 배출 가이드나 과태료 기준 데이터를 수정하거나 추가한다 |
| Dynamics | 환경부의 지침 변경이나 신규 품목 등록을 위해 시스템의 기준 데이터를 업데이트하는 경우 |
| Goals | 모든 사용자에게 항상 신뢰성 있는 최신 데이터를 보장한다 |

## 5. Problem statement

1) 다양한 검색어 처리의 어려움
사람마다 쓰레기를 부르는 이름이 다릅니다.(예: 생수병, 페트병) 어떤 단어르 입력해도 독똑하게 같은 결과를 보여주는 것이 기술적인 숙제입니다.
  
2) 복잡하고 자주 바뀌는 규칙
환경부 지침이나 과태료 기준이 갑자기 바뀔 때, 시스템의 데이터를 빠르고 정확하게 업데이트해서 사용자에게 틀린 정보를 주지 않도록 관리하는 것이 중요합니다.

3) 사용자의 귀찮음 해소
분리수거는 귀찮은 일입니다. 정보를 찾는 과정이 복잡하면 사용자가 포기할 수 있으므로, 최대한 적게 타이핑하고 빨리 결과를 보여주는 방법을 찾아야 합니다.

NFR
1) 스마트폰이나 컴퓨터를 잘 다루지 못하는 사람도 바로 검색할 수 있도록 해야합니다.
2) 쓰레기를 버리기 직전에 사용할 서비스이기 때문에 검색 결과가 빨리 나와야 합니다.
3) 잘못된 정보를 제공해서 사용자에게 불이익이 없도록 데이터의 정확성을 100%로 유지해야 합니다.
